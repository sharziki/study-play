# Discrete mathematics essentials

A proposition is a statement that is either true or false. The negation of a proposition P, written not P, reverses its truth value. The implication P implies Q is false only when P is true and Q is false. Its contrapositive, not Q implies not P, is logically equivalent to the original implication.

A set is an unordered collection of distinct objects. The union A union B contains elements in A, B, or both. The intersection A intersection B contains only elements shared by both sets. De Morgan's law states that the complement of a union equals the intersection of the complements.

A function from A to B assigns every element of A exactly one element of B. It is injective when distinct inputs have distinct outputs. It is surjective when every element of B is an output. A function is bijective when it is both injective and surjective, and only bijections have inverse functions defined on the entire codomain.

Mathematical induction proves a statement for every integer from a starting point onward. First prove the base case. Then assume the statement is true for an arbitrary integer k and use that assumption to prove it for k plus one. The base case anchors the chain; the inductive step extends it.

In a graph, vertices represent objects and edges represent relationships. A path is a sequence of adjacent vertices. A connected graph has a path between every pair of vertices. A tree is a connected graph with no cycles, and every tree with n vertices has exactly n minus one edges.
